КЛУБ БАРБЕРОВ — ВЕРСИЯ ДЛЯ BEGET (PHP + MySQL)

ВАЖНО: проект больше НЕ использует Supabase. Все данные хранятся в MySQL на Beget.
Требуется PHP 7.4+ и MySQL 5.7+ (предпочтительно PHP 8.1+).

1. В панели Beget создайте НОВЫЙ сайт/поддомен для этого проекта. Не меняйте папку существующего сайта.
2. В файловом менеджере нового сайта откройте его public_html и загрузите содержимое архива (index.html должен лежать прямо в public_html).
3. В Beget откройте раздел Базы данных MySQL, создайте базу и пользователя, назначьте пользователя этой базе с полными правами. Сохраните имя базы, пользователя и пароль.
4. Откройте phpMyAdmin этой базы. Выберите базу, вкладка Импорт, загрузите database.sql и выполните импорт.
5. В файловом менеджере скопируйте config.php.example в config.php. Отредактируйте config.php и внесите точные db_host, db_name, db_user, db_pass из Beget. Обычно db_host = localhost, но используйте значение, указанное в панели Beget.
6. Включите SSL/Let's Encrypt для домена и проверьте сайт по https://.
7. Откройте https://ВАШ-ДОМЕН/admin.html. Разверните «Первый вход? Создать администратора», зарегистрируйте почту и пароль (не менее 10 символов). Первый успешный аккаунт становится единственным администратором. После него публичная регистрация навсегда закрывается.
8. Войдите в админку. Для проверки отправьте тестовую заявку с главной страницы.

БЕЗОПАСНОСТЬ:
- Не публикуйте и не отправляйте никому config.php.
- Не используйте пароль от панели Beget как пароль базы.
- Первый администратор должен регистрироваться только вами, до публикации ссылки на сайт.
- Не удаляйте database.sql до импорта (после настройки его можно оставить; доступ к нему закрыт .htaccess).
- Если в аккаунте Beget уже есть сайт, создайте отдельный сайт и отдельную директорию. Не распаковывайте архив поверх первого проекта.

ОГРАНИЧЕНИЕ ТЕКУЩЕЙ ВЕРСИИ:
В админке доступны вход, создание партнёрских ссылок, заявки, ручной учёт оплат и UTM. Сводная аналитика событий/партнёров базовая; дневной график пока не формируется. Автоматическое списание денег и приём платежей не реализованы.
