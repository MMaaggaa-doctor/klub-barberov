# Клуб Барберов — сайт (хостинг Beget, PHP + MySQL)

Сайт состоит из обычных страниц (HTML, CSS, JS) и одного серверного файла `api.php`, который сохраняет заявки, события аналитики, партнёров и оплаты в базу MySQL. Всё, что чаще всего меняется, вынесено в `js/config.js`.

## 1. Запуск на Beget (новый сайт рядом с уже существующим)
Существующий проект не трогаем: у каждого сайта на Beget своя папка, и новый сайт кладётся в отдельную. Названия пунктов в панели могут немного отличаться.

1. **Домен.** В панели Beget создайте новый сайт: либо на отдельном домене, либо на поддомене уже имеющегося (например, `club.вашдомен.ru`). Запомните папку сайта, она вида `имя_сайта/public_html`. Пока домена нет, можно проверять на технической ссылке `…beget.tech`.
2. **База данных.** Раздел MySQL: создайте базу и пользователя. Запишите три значения: имя базы, пользователь, пароль (Beget обычно добавляет к ним ваш логин).
3. **Файлы.** Распакуйте архив на компьютере. Загрузите **содержимое папки `site`** в `public_html` нового сайта, чтобы `index.html` лежал прямо в `public_html`. Способы: файловый менеджер в панели (можно загрузить архив и распаковать там же) или FTP. Скрытые файлы (`.htaccess`) тоже должны попасть на сервер.
4. **Таблицы.** Откройте phpMyAdmin из панели, выберите свою базу, вкладка «SQL» (или «Импорт»): вставьте или загрузите `database.sql`. Файл можно запускать повторно, ничего не сломается.
5. **Доступы к базе.** В `public_html` скопируйте `config.php.example` в `config.php` и впишите туда данные из шага 2. `config.php` закрыт от просмотра из интернета.
6. **PHP.** В настройках сайта выберите PHP 7.4 или новее.
7. **SSL.** В панели подключите бесплатный сертификат Let's Encrypt. После этого в `.htaccess` раскомментируйте три строки про https.
8. **Администратор.** Откройте `ваш-сайт/admin.html`. Пока администратора нет, вы увидите форму «Первый запуск»: введите почту и придумайте пароль (минимум 10 символов). **Тот, кто зарегистрируется первым, становится администратором, после этого регистрация закрыта.** Поэтому сделайте это сразу после запуска. Из подвала сайта сюда же ведёт почти незаметный замок.
9. **Адрес сайта.** Найдите `YOUR-SITE.netlify.app` в `index.html`, `materials.html`, папке `materials/`, `sitemap.xml`, `robots.txt` и замените на свой домен.

Если потеряли пароль: в phpMyAdmin выполните `DELETE FROM admins;` и зарегистрируйтесь на `admin.html` заново.

## 2. Где что менять
| Что нужно | Где |
|---|---|
| Ссылки кнопок (вступить, тарифы, разбор, карточки уроков) | `js/config.js` → `LINKS` |
| Номер счётчика Яндекс Метрики | `js/config.js` → `METRIKA_ID` |
| Процент вознаграждения амбассадоров | `js/config.js` → `REWARD_PERCENT` |
| Цена подписки в калькуляторе | `js/config.js` → `CLUB_PRICE` |
| Тёмный или белый первый экран | `js/config.js` → `HERO_STYLE` (`'dark'` или `'light'`); предпросмотр: `сайт/?hero=light` |
| Скриншоты чата в телефоне | файлы в `assets/chat/`, список в `js/config.js` → `CHAT_SHOTS` |
| Доступы к базе | `config.php` |
| Тексты и блоки главной | `index.html`, каждый блок подписан комментарием (`<!-- CASES -->`, `<!-- PAIN -->`, `<!-- CLOSED CHAT -->`, `<!-- CALCULATOR -->`, `<!-- FEATURES -->`, `<!-- REVIEWS -->`, `<!-- PRICING -->`, `<!-- FAQ -->`…) |
| Страница «Бесплатные уроки» и статьи | `materials.html`, папка `materials/` |
| Цвета, шрифты, отступы | `css/style.css` (цвета — в начале, `:root`) |
| Картинки | `assets/img/` (фото Теймура — `teymur.jpg`, круглый логотип — `logo.png`), `assets/cases/`, `assets/3d/` |

Чтобы новая кнопка попала в аналитику, добавьте ей атрибуты: `data-goal="join_click"` (цель) и `data-link="join"` (ключ ссылки из `LINKS`). Для тарифов ещё `data-plan="month"`, `year` или `trial`.

При обновлении сайта заливайте изменённые файлы поверх, **не перезаписывая `config.php`**.

## 3. Админка (`admin.html`)
- **Партнёры:** создать ссылку (по одной или списком), посетители, заявки, оплаты, сумма и вознаграждение, график за 30 дней, отключить или удалить.
- **Воронка:** зашли → нажали кнопку → перешли к оплате → оплатили, плюс разбивка по источникам (метка партнёра или utm_source).
- **Заявки:** заявки с формы с источником. Кнопка «Оплатил» переносит человека во вкладку оплат.
- **Оплаты:** внесение оплат вручную (источник, тариф, сумма, дата). Вознаграждение = сумма оплат партнёра × `REWARD_PERCENT`. Если человек платит каждый месяц, вносите каждую оплату.
- **Ссылки UTM:** генератор ссылок для постов, рилсов, рекламы.
- Внизу можно сменить пароль.

## 4. Отслеживание посетителей
**Что запоминается.** При заходе по ссылке с `?ref=метка` или `utm_*` источник хранится в браузере 30 дней (последний заход) и прикрепляется ко всем событиям и заявке.

| Цель | Когда |
|---|---|
| `pageview` | зашли на страницу (один раз за сессию) |
| `join_click` | «Вступить», «Записаться на обучение», «Попасть в чат» |
| `plan_select` | выбор тарифа: месяц, год или пробная неделя (параметр `plan`) |
| `pay_click` | переход к оплате (вместе с `plan_select`) |
| `free_review_click` | «Записаться на бесплатный разбор» |
| `lead_submit` | отправка формы заявки |
| `view_pricing`, `view_cases` | дошли до тарифов / до блока «Было — Стало» |
| `cta_click` | прочие кнопки |

**Успешная оплата** происходит вне сайта (Telegram или платёжная страница), поэтому её вносят в админке вручную.

**Яндекс Метрика.** Впишите номер счётчика в `METRIKA_ID`: подключится счётчик с Вебвизором, картой кликов и целями. В кабинете Метрики создайте цели типа «JavaScript-событие» с названиями из таблицы. В России на сайте нужно указать, что собираются данные посетителей (политика конфиденциальности).

**Метка в Telegram.** Если кнопка ведёт на бота (`https://t.me/имя_бота`), к ссылке добавляется `?start=источник-идентификатор`, например `?start=ivan-7dxv48`. Бот может разделить значение по последнему дефису. На ссылки-посты каналов и личные аккаунты метку добавить нельзя: Telegram передаёт её только боту. К обычным внешним ссылкам (страница оплаты) добавляются `utm_*`, `ref` и `cid`.

Ограничения: «посетители» считаются по браузеру; роботы и поисковики не считаются.

## 5. Безопасность
- Пароль хранится только в виде хеша; вход ограничен по числу попыток; сессия живёт 12 часов без действий.
- Запросы, меняющие данные, принимаются только с самого сайта.
- `config.php`, `database.sql` и служебные файлы закрыты в `.htaccess`.
- Не публикуйте `config.php` на GitHub (он в `.gitignore`).
