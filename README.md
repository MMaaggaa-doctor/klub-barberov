# Клуб Барберов — сайт

Обычный статический сайт (HTML, CSS, JS). Сборка не нужна.

## 1. Что заменить перед запуском
1. **Фото Теймура** лежит в `assets/img/teymur.jpg`. Новое фото кладите под тем же именем (квадрат или 4:5).
2. **Круглый логотип**: положите квадратный файл `assets/img/logo.png` (например 256×256). Он сам станет кружком в шапке на всех страницах. Пока файла нет, показывается кружок «КБ».
3. **Скриншоты чата**: файлы в `assets/chat/`, перечислить в `js/config.js` в списке `CHAT_SHOTS`. Пока список пуст, в телефоне идёт анимированный пример.
4. **Видео (VSL)**: на главном экране и на странице «Бесплатные уроки» стоит рамка-заглушка.
5. **Адрес сайта**: найти `YOUR-SITE.netlify.app` в файлах `index.html`, `materials.html`, папке `materials/`, `sitemap.xml`, `robots.txt` и заменить на свой домен.
6. **Ссылки карточек «Бесплатные уроки»**: в `js/config.js` в параметре `MATERIAL_LINKS` (income, guide, books). Пока пусто, карточки ведут в Telegram.
7. **Цена в калькуляторе**: `CLUB_PRICE` в `js/config.js`.
8. **3D-модели**: кладите в `assets/3d/` под теми же именами (WEBP/PNG с прозрачным фоном).

## 2. Supabase: заявки, партнёрские ссылки, админка
1. Создайте проект на supabase.com.
2. SQL Editor → New query → вставьте весь файл `supabase/schema.sql` → Run.
3. Затем отдельным запросом, со своей почтой:
   `insert into public.admins (email) values ('ВАША_ПОЧТА@example.com');`
4. Authentication → Users → Add user: ваша почта и пароль (отметьте автоподтверждение).
   Затем в настройках Authentication отключите регистрацию новых пользователей.
5. Project Settings → API: скопируйте Project URL и ключ `anon public` (или Publishable) в `js/config.js`
   (`SUPABASE_URL` и `SUPABASE_ANON_KEY`). Ключ `service_role` / `secret` никуда не вставляйте.

### Как пользоваться админкой
- Откройте `ВАШ-САЙТ/admin.html`, войдите почтой и паролем.
- «Новая партнёрская ссылка»: введите имя партнёра, метка в ссылке подставится сама. Нажмите «Создать ссылку» и отдайте партнёру ссылку вида `сайт/?ref=метка`.
- В таблице видно переходы, уникальных посетителей, заявки с формы и динамику за 30 дней по каждому партнёру. Ссылку можно отключить или удалить.
- Учёт идёт на самом сайте: переход по ссылке записывается один раз за визит; заявка с формы привязывается к партнёру, который привёл человека в последние 30 дней.
- Заявки без партнёра смотрите в Supabase: Table Editor → leads.

Ограничения: «уникальные» считаются по браузеру; роботы и поисковики не считаются; покупка в Telegram не отслеживается, только переходы на сайт и заявки с формы.

## 3. Выкладка: GitHub + Netlify
1. Создайте репозиторий на GitHub и загрузите в него все файлы (index.html в корне).
2. На netlify.com: Add new site → Import an existing project → GitHub → ваш репозиторий. Build command пустой, Publish directory `.`
3. Каждое изменение в GitHub будет автоматически обновлять сайт.

## 4. Новая статья
Скопируйте любой файл из `materials/`, поменяйте текст и добавьте карточку в `materials.html` и запись в `sitemap.xml`.
